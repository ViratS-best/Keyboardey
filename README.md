# Keyboardey

A weird keyboard CAD design created for the [Half Life](https://halflife.hackclub.com/) challenge.

## Overview

Keyboardey is a weird, funky, custom-designed keypad layout built entirely from scratch. This project was my second time ever using CAD, making it a deep dive into learning how to design mechanical parts, shape custom keys, and handle complex key cutout geometry in a 3D modeling environment.
